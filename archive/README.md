# Conversation archive protocol

This directory stores **curated summaries and references**, not automatic ChatGPT exports.

1. Confirm scope, project title, known chat URL and time zone.
2. Capture dated decisions and links to approved deliverables with verification status.
3. Link related commits, issues and pull requests.
4. Summarize remaining tasks, responsible workstream, and cross-project dependencies.
5. Mark workstream complete only after owner review and final handoff.
6. The user archives the ChatGPT feed separately; do **not** imply this action was performed.
7. Archive metadata must distinguish verified timestamps from approximate dates.
8. Keep personal/private data and access secrets out of this public repository.

Each finished workstream should include a record using `templates/CONVERSATION_RECORD.md`.
