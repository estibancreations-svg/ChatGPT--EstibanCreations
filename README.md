# Estiban Creations — Conversation & Work Registry

**Owner:** Estiban Creations / The Architect  
**Repository role:** searchable coordination registry for ChatGPT work, decisions, deliverables, and external source-of-truth references.  
**Established:** 2026-11-17 (America/Chicago)

This repository does **not** automatically ingest ChatGPT conversation transcripts. Only summaries and materials deliberately exported or saved here are preserved. Do not store API keys, passwords, private client information, sponsor contract secrets, or copyrighted source files without authorization. This repository is currently **public**.

## Operating standard
- One ChatGPT conversation per major project or bounded workstream.
- Each project receives a `PROJECT.md`, dated decision log, deliverable manifest, and task register.
- Source records reference **actual** verified ChatGPT share links or conversation URLs (when supplied). Never invent chat IDs, message timestamps, or archive status.
- Maintain an `origin` field (conversation title, approximate date, user-provided URL, related repo/issue) and `verified_at` for facts derived from external systems.
- Do not confuse a planning document with implemented software, live accounts, approved spending, or a published episode.
- Close a workstream only with a final summary, deliverable links, unresolved items, and handoff instructions. GitHub archival means record closure; manually archive the ChatGPT feed in the app.
- Cross-reference related workstreams using links; never duplicate competing source-of-truth assets.
- Major external writes, publication, expenditures, and brand/legal commitments require the Architect's approval.
